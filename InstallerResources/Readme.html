Before you install

The installer places these compiled plugins in the system plugin folders:

/Library/Audio/Plug-Ins/Components/IRChoir.component
/Library/Audio/Plug-Ins/VST3/IRChoir.vst3

The AU is a MIDI-controlled audio effect. Host routing varies; input audio is required even when MIDI notes are used.

Restart your DAW and rescan plugins after installation. Read the included Quick Start and User Guide before editing important projects.

The default build is unsigned and not notarized. Only install a build whose source and origin you trust. Do not disable Gatekeeper globally.

Custom presets are stored separately under the user's application-data location. Removing the plugins does not remove those presets.

Known limitations and executed test results are in the included Release and Test Report. Listening tests and target-host verification are still required.

CREATE A MAC INSTALLER
  On a Mac with CMake and Xcode command line tools, double-click:
  Build-I.R.Choir.command

  Or upload this folder's contents, INCLUDING .github, to the root of a
  dedicated GitHub repository. Push to main/master or run the Mac build
  workflow in Actions. After a SUCCESSFUL workflow, download its DMG artifact.

THE GENERATED DMG IS DESIGNED TO CONTAIN
  A branded Apple package installer for IRChoir.component (AU) and
  IRChoir.vst3, the PDF guides, audit, licenses and corresponding source.
  Actual Mac build, validation and installation have not yet been run here.

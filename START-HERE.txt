I.R.CHOIR 0.3.2 - SOURCE FOLDER

The Complete Package contains the Mac AU/VST3 installer in Installer/.
Read Documentation/IRChoir-Quick-Start.pdf, IRChoir-User-Guide.pdf and
IRChoir-Release-and-Test-Report.pdf for current instructions and audit evidence.
The report identifies the validated source commit and Mac workflow run.

The default installer is unsigned and unnotarized. Real DAW listening and
compatibility checks remain. Read AUDIT.md for coverage and limitations.

Rebuild on a Mac with CMake and Xcode command line tools:
  bash Scripts/build-mac.sh
Or double-click Build-I.R.Choir.command.
